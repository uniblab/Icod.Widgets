# Icod.Widgets 1.6.2

Icod.Widgets 1.6.2 is a focused Windows console interoperability dependency
release. It updates the sole direct runtime dependency from Icod.DCurses 2.5.1
to Icod.DCurses 2.5.2 without changing the Widgets runtime implementation.

## Why upgrade

Icod.DCurses 2.5.2 consumes Icod.Terminal 1.29.2. On system-backed Windows
sessions, Terminal temporarily selects UTF-8 console-output decoding so Unicode
box-drawing characters retain one-cell geometry. Raw and CBreak sessions also
own mouse input and suppress Quick Edit while active, allowing requested mouse
reports to reach the existing DCurses and Widgets input layers. Session cleanup
restores the exact prior console input mode and output code page.

These platform corrections address the environment beneath Widgets menus,
dialogs, borders, and editors. The existing Widgets menu and dialog behavior is
unchanged: Alt mnemonics, pointer activation, cascading submenu overlays,
theme-controlled hover, and matching press/release dialog choices continue to
use the 1.6 implementation.

## Mouse protocols remain explicit

The dependency update does not enable terminal mouse reporting automatically.
Applications continue to acquire the DCurses input-protocol lease appropriate
to their behavior. The shared Widgets sample loop requests `AnyMotion` because
the gallery demonstrates optional pointer-hover styling in addition to clicks
and captured drags. Applications that need presses, releases, and wheel events
without hover can request the narrower supported mouse mode.

## Compatibility

- There are no public API changes.
- There are no Widgets runtime implementation changes.
- `AssemblyVersion` remains `1.0.0.0`.
- Target frameworks remain .NET 8, .NET 9, and .NET 10.
- Icod.DCurses 2.5.2 remains the sole direct runtime dependency.
- Raw-mode Alt, `Ctrl+C`, and `Ctrl+Z` application delivery from 1.6.1 remains
  available through the updated dependency chain.

## Verification

The automated matrix builds and tests all three target frameworks on Windows,
Linux, and macOS, runs every sample smoke workflow, inspects the exact package
and symbols, and restores the package-only consumer. The sample guide contains
the separate live Windows checks for borders, menus, submenu placement, dialog
clicks, and editor undo.

## Install

```text
dotnet add package Icod.Widgets --version 1.6.2
```
