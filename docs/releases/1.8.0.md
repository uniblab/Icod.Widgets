# Icod.Widgets 1.8.0 — Generic Dialog Actions

Icod.Widgets 1.8.0 makes message-dialog choices generic. Applications can now
use an action array to define captions, semantic values and outcomes, mnemonics,
the default action, and cancel behavior independently. This supports decisions
such as **Yes / Don't Save / Cancel** without teaching the widget application
policy.

## Highlights

- `WidgetMessageDialog` accepts an `IReadOnlyList<WidgetDialogAction>`, exposes a
  read-only `Actions` snapshot, and provides controlled `SetActionEnabled`.
- `WidgetDialogAction.Mnemonic` binds a plain, case-insensitive character.
  `IsDefault` controls Enter and `IsCancel` controls Escape.
- Every choice uses bracketed presentation. Unicode captions are measured in
  terminal display columns for both rendering and pointer hit testing.
- Enter, Escape, mnemonics, and pointer clicks resolve to the same action and
  therefore the same `WidgetDialogResult` value and outcome.
- Form-dialog actions use the same mnemonic, default, cancel, enabled-selection,
  and measured-button rules while keeping asynchronous validation intact.
- Per-dialog `Styles` remain strictly presentation-only. A warning can use a red
  surface, text, border, title, and button palette without changing behavior.

## Compatibility and migration

The existing `WidgetMessageDialog.YesNo(string, string, string)` member remains
present and behaves as before for binary compatibility. It is now marked
warning-level obsolete. New source should express the complete decision:

```csharp
IReadOnlyList<WidgetDialogAction> actions = [
    new("yes", "Yes", WidgetDialogOutcome.Yes) { Mnemonic = 'Y' },
    new("no", "Don't Save", WidgetDialogOutcome.No) { Mnemonic = 'N' },
    new("cancel", "Cancel", WidgetDialogOutcome.Cancel) {
        Mnemonic = 'C', IsDefault = true, IsCancel = true
    }
];
WidgetMessageDialog dialog = new(
    "close", "Unsaved changes", "Do you want to save these changes?", actions
);
```

Captions no longer imply application behavior: consumers inspect the returned
value/outcome. If a consumer disables actions dynamically, at least one choice
must remain enabled.

## Release identity

- Package version: `1.8.0`
- AssemblyVersion: `1.0.0.0`
- Targets: `net8.0`, `net9.0`, `net10.0`
- Sole direct runtime dependency: `Icod.DCurses 2.5.2`

The stable assembly identity and retained legacy member preserve binary
compatibility; the generic dialog surface is additive.
