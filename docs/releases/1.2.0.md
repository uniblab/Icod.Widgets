# Icod.Widgets 1.2.0

Icod.Widgets 1.2.0 provides reusable document-workspace controls while
preserving the 1.0 assembly identity and the 1.1 editing foundation.

## Highlights

- `WidgetTabStrip` accepts stable-key snapshots with compact overflow and emits
  activation and close requests. The application decides whether to switch or
  close a document.
- `WidgetContentHost` presents one caller-owned tree at a time. Separate text
  views retain their selection and scroll state; detachment invalidates pending
  input and clipboard work.
- Menus accept caller-controlled presentation and route focused edit commands;
  status fields may expose commands while existing inert fields stay inert.
- Composable form dialogs offer explicit Save, Don't Save, and Cancel results.
  A separate save-target provider inspects a proposed target without writing it.
- Find/Replace and Go To Line forms produce typed, guarded requests. Applications
  own search execution, document edits, and file I/O.

## Try it

Install `Icod.Widgets` version `1.2.0` or run the
[in-memory workspace sample](https://github.com/uniblab/Icod.Widgets/tree/main/samples/Icod.Widgets.Workspace.Sample):

```text
dotnet run --project samples/Icod.Widgets.Workspace.Sample -c Release -f net10.0
```

The sample starts with three independent documents. It demonstrates switching,
close decisions, Find/Find Next, F6 focus movement, an empty workspace, Save As
inspection, and actionable status without writing files. See the [sample guide](https://github.com/uniblab/Icod.Widgets/blob/main/samples/README.md)
and [controls guide](https://github.com/uniblab/Icod.Widgets/blob/main/docs/Controls-and-Interaction.md).

## Compatibility and qualification

The package targets net8.0, net9.0, and net10.0; keeps assembly version
`1.0.0.0`; and directly depends only on `Icod.DCurses 2.4.0`. The
[1.2 public API baseline](https://github.com/uniblab/Icod.Widgets/blob/main/docs/Public-API-Baseline-1.2.md)
records the additive surface and older-consumer checks. See
[W1211 qualification](https://github.com/uniblab/Icod.Widgets/blob/main/docs/W1211-Stable-Qualification.md)
for exact automated and live-terminal coverage.

Applications retain ownership of paths, encoding, document lifetime, conflict
handling, safe saves, and search execution. Printing, split views, file watching,
recovery, and a regex engine are outside this release.
