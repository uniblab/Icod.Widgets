# Icod.Widgets 1.6.1

Icod.Widgets 1.6.1 is a focused dependency correction for the 1.6 menu and
dialog release. It changes the sole direct runtime dependency from
Icod.DCurses 2.5.0 to Icod.DCurses 2.5.1.

## Why upgrade

DCurses 2.5.1 consumes Terminal 1.29.1, which corrects legacy Alt-prefix input
such as `Alt+F` and ensures raw-mode `Ctrl+C` and `Ctrl+Z` reach applications as
Control-modified character events. This restores the intended dependency chain
for Widgets menu mnemonics and editor-style shortcuts.

Applications that own `Ctrl+C` or `Ctrl+Z` must still open their DCurses session
in raw input mode. CBreak remains appropriate when the host should retain its
normal interrupt and suspend processing.

## Compatibility

- There are no public API changes.
- There are no Widgets runtime implementation changes.
- `AssemblyVersion` remains `1.0.0.0`.
- Target frameworks remain .NET 8, .NET 9, and .NET 10.
- Icod.DCurses 2.5.1 remains the sole direct runtime dependency.

## Install

```text
dotnet add package Icod.Widgets --version 1.6.1
```
