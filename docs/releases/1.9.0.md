# Icod.Widgets 1.9.0 — Editor Viewport Scrollbar

Icod.Widgets 1.9.0 adds an opt-in, auto-hidden vertical scrollbar to the
multiline editor. It scrolls the viewport in displayed rows, so a wrapped
continuation is a first-class scroll position without changing public logical
line and character reporting.

## Highlights

- `WidgetEditorOptions.ShowVerticalScrollBar` reserves the extreme-right column
  only while content overflows at full editor width. Fitting documents and
  one-row layouts remain scrollbar-free without visibility oscillation.
- Ctrl+Up and Ctrl+Down step one displayed row. The mouse wheel keeps its
  three-row step; pointer presses on the arrow buttons step one row, track
  presses page, and thumb dragging reaches both document boundaries.
- When scrolling would move the caret out of view, it is clamped to the
  approaching viewport edge at its preferred visual column. A visible caret
  and selection are not changed.
- The scrollbar renders standard `▲`, `▼`, `│`, and `┃` glyphs through the
  existing `ScrollTrack`, `ScrollThumb`, `ScrollFocusedThumb`, and `Disabled`
  theme roles. Themes affect presentation, not scrolling behavior.
- The right scrollbar composes with the fixed left line-number gutter. Row-map
  discovery and projection remain bounded for large documents and long wrapped
  lines, refining conservative scrollbar ranges as content is visited.

## Compatibility

The release adds one semantic public member:
`WidgetEditorOptions.ShowVerticalScrollBar`. Its default is `false`, preserving
existing layouts. `WidgetTextViewState.VerticalOffset` and `SetScroll` retain
their logical-line contract; wrapped-row anchors remain internal.

## Dedit integration contract

After 1.9.0 is published, Dedit should update its package reference, set
`ShowVerticalScrollBar = true` on document editors, and apply any desired
presentation through the existing scrollbar theme roles. The gutter,
current-line band, wrapped-row navigation, caret clamping, and status position
remain owned by Widgets; Dedit should not duplicate scrollbar rendering,
hit-testing, or viewport synchronization.
