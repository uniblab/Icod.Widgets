# Icod.Widgets 1.7.2

Icod.Widgets 1.7.2 corrects completion of a paste whose text is identical to
the selected text. It is a focused patch release with no public API additions.

## Identical paste completion

Replacing a selection with identical text does not change the document, so the
document layer correctly reports the operation as `NoChange`. The editor now
still applies the requested post-paste selection state: the selection collapses
and the caret moves to the end of the pasted text.

Because the text is unchanged, the operation does not increment the document
revision, emit a text-edited action, or create an undo entry. A different paste
continues to replace the selection as one ordinary undoable edit.

## Menu and accelerator equivalence

Pointer activation and keyboard shortcuts use the same focused edit-command
dispatcher. Clicking Edit > Paste closes the menu, restores editor focus, and
issues the same focused-editor clipboard request as Ctrl+V. The correction is
therefore shared by menu clicks and accelerators rather than implemented as a
separate pointer-only paste path.

## Compatibility

The correction is internal and does not change the public API. `AssemblyVersion`
remains `1.0.0.0`, target frameworks remain .NET 8, .NET 9, and .NET 10, and
Icod.DCurses 2.5.2 remains the sole direct runtime dependency.

## Verification

Automated coverage verifies that pointer and Ctrl+V activation produce the same
clipboard operation, view, document, and selection coordinates. It also verifies
that an identical paste collapses the selection while preserving document text,
revision, and undo history on every supported target framework.

## Install

```text
dotnet add package Icod.Widgets --version 1.7.2
```
