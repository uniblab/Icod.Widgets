# Icod.Widgets 1.3.1

Icod.Widgets 1.3.1 corrects cached editor-line invalidation so typed
characters remain visible in document editors after a blank render and while
appending to existing content.

## Highlights

- `WidgetTextProjection` now invalidates a cached line when insertion starts at
  that line's previous end position.
- The correction restores the first visible character typed into a blank editor
  and later characters appended to a previously rendered nonempty line.
- The patch includes regression coverage for both empty-line typing and
  nonempty-line append behavior.

## Try it

Install in a .NET project with `dotnet add package Icod.Widgets --version 1.3.1`.
To run the gallery from a fresh checkout:

```text
git clone https://github.com/uniblab/Icod.Widgets.git
cd Icod.Widgets
dotnet run --project samples/Icod.Widgets.Gallery.Sample -c Release -f net10.0
```

See the [root README](https://github.com/uniblab/Icod.Widgets/blob/main/README.md)
for the application-loop example and the
[editor sample guide](https://github.com/uniblab/Icod.Widgets/blob/main/samples/Icod.Widgets.Editor.Sample/README.md)
for the in-memory editor's controls and application ownership boundaries.

## Compatibility and scope

Targets net8.0, net9.0, and net10.0; assembly version `1.0.0.0`; sole direct
dependency `Icod.DCurses 2.5.0`. The change is internal, retains the public
API, and does not alter application-owned document lifetime, search execution,
file writes, or presentation loops.
