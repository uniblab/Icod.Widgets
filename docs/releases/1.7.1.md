# Icod.Widgets 1.7.1

Icod.Widgets 1.7.1 corrects vertical caret movement in wrapped multiline text.
It is a focused patch release with no public API additions.

## Wrapped visual-row navigation

Up and Down now move between adjacent visual rows produced by word or text-
element wrapping. Movement first traverses continuation rows within the current
logical line and then crosses to the neighboring logical line. Page Up and Page
Down use the same model and count visual rows instead of logical lines.

The editor retains a preferred visual column for the entire vertical movement
sequence. A short wrapped row or short logical line temporarily clamps the
caret to the closest available position; moving again to a wider row restores
the preferred column. Shift+Up, Shift+Down, Shift+Page Up, and Shift+Page Down
extend the selection through those same visual-row destinations.

At a soft-wrap boundary, one document offset can identify both the end of the
preceding row and the start of the continuation row. The view now retains that
internal leading/trailing affinity so the caret is rendered on the destination
row selected by navigation.

## Logical coordinates and compatibility

Wrapping remains a presentation concern. Caret and selection values exposed by
`WidgetTextViewState` remain logical UTF-16 document offsets; applications can
continue to report real logical line and character positions without converting
them to visual-row coordinates.

The correction is internal and does not change the public API. `AssemblyVersion`
remains `1.0.0.0`, target frameworks remain .NET 8, .NET 9, and .NET 10, and
Icod.DCurses 2.5.2 remains the sole direct runtime dependency.

## Verification

Automated coverage exercises wrapped Up/Down traversal in both directions,
preferred-column restoration across short rows, soft-wrap boundary placement,
Page Up/Page Down row counting, and Shift-extended selection on every supported
target framework.

## Install

```text
dotnet add package Icod.Widgets --version 1.7.1
```
