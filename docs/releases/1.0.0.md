# Icod.Widgets 1.0.0 Release Notes

Icod.Widgets is a reusable terminal-control library for .NET 8, 9 and 10. It builds on Icod.DCurses 2.3.1 and leaves the application in control of its event loop, commands, validation, filesystem operations and lifetime.

## Controls

- Labels, buttons, text input, checkboxes, radio groups, borders and scroll indicators.
- Single- and multi-select lists with stable keys, keyboard search and bounded scrolling; drop-down selection with preview, commit and cancel.
- Menu bars, framed popup menus and submenus with disabled, checkable and separator items. `Alt+F` or `Alt+V` opens a top-level menu; a plain mnemonic acts in the open menu; an independent `Ctrl` shortcut invokes its command without entering menu navigation.
- Captioned, framed OK, OK/Cancel and Yes/No message dialogs, plus a Previous/Next/Cancel wizard shell. Escape reports `Cancel` even in an OK-only or Yes/No dialog.
- Provider-backed folder and existing-file pickers with roots/drives, path entry, filters, multiple-file basket and stale-result rejection.
- Domain-neutral inventory/action lists, bounded message history, status fields, help overlays and text/number prompts.

Popup and dialog borders use the theme and retain usable compact fallbacks. Modal scopes isolate background focus and commands, and closing a retained overlay preserves the borrowed application background.

## Samples and package

The repository includes interactive gallery, editor and roguelike samples, with deterministic smoke modes. The samples and tests are GPL-3.0-or-later and are excluded from the library package. The DLL package is LGPL-3.0-or-later and has one direct runtime package dependency, `Icod.DCurses 2.3.1`. A matching symbol package is published for source-level debugging.

Install after publication:

```text
dotnet add package Icod.Widgets --version 1.0.0
```

See the [README](../../README.md) for host ownership, keyboard interaction, picker integration and limits, and the [changelog](../../CHANGELOG.md) for the complete release-candidate history.

## Release qualification

The [W1014 worksheet](../W1014-Stable-Qualification.md) records exact-head live terminal acceptance separately from automated tests. Complete applicable Windows, macOS and Linux lanes before tagging. The tag-triggered release workflow rebuilds and tests the library, checks the exact package and symbols, runs the samples and package-only consumer, then publishes to NuGet.org and GitHub Packages and creates a checksum-bearing GitHub Release.
