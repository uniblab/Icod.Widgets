# Icod.Widgets 1.7.0

Icod.Widgets 1.7.0 adds an opt-in, theme-controlled current-line treatment to
the multiline editor. It makes the caret's logical line recognizable at a
glance without confusing that line with selected text.

## Current-line behavior

Construct `WidgetTextEditor` with
`new WidgetEditorOptions { HighlightCurrentLine = true }` to enable the band.
The editor paints `WidgetStyleRole.EditorCurrentLine` across the complete text
viewport width, including empty cells to the right of the line's content.
When a logical line wraps, each of its visible visual rows receives the same
treatment. Moving the caret moves the band to the new logical line.

Selection is painted after the current-line background. Active and inactive
selection styles therefore retain precedence, so selected text remains
unambiguous even when it overlaps the current line.

## Themes and compatibility

The built-in dark and light palettes provide a muted neutral current-line
background when the terminal advertises the required color axis. Applications
can replace the complete `EditorCurrentLine` style through `WidgetTheme.Parts`
or a scoped editor `Styles` override. Terminals lacking the required color
capability safely fall back through the existing theme rules.

The option is disabled by default, preserving existing presentation. The two
public additions are additive: one `WidgetEditorOptions` property and one style
role appended to `WidgetStyleRole`. `AssemblyVersion` remains `1.0.0.0`, target
frameworks remain .NET 8, .NET 9, and .NET 10, and Icod.DCurses 2.5.2 remains
the sole direct runtime dependency. The separate line-number gutter remains
outside this release.

## Sample and verification

The editor sample enables the option. Move through short and wrapped lines to
verify that the full-width band follows the logical caret line, then select text
across that line to confirm selection remains visually dominant. Automated
tests cover default-off compatibility, full-width styling, wrapped logical
lines, caret movement, and selection precedence on all supported frameworks.

## Install

```text
dotnet add package Icod.Widgets --version 1.7.0
```
