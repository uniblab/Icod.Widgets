# Icod.Widgets 1.7.0

Icod.Widgets 1.7.0 adds opt-in, theme-controlled current-line and line-number
presentation to the multiline editor. Together they make the caret's logical
line and the document's structure recognizable at a glance without confusing
either presentation with selected text.

## Current-line behavior

Construct `WidgetTextEditor` with
`new WidgetEditorOptions { HighlightCurrentLine = true }` to enable the band.
The editor paints `WidgetStyleRole.EditorCurrentLine` across the complete text
viewport width, including empty cells to the right of the line's content.
When a logical line wraps, each of its visible visual rows receives the same
treatment. Moving the caret moves the band to the new logical line.

Selection is painted after the current-line background. Active and inactive
selection styles therefore retain precedence, so selected text remains
unambiguous even when it overlaps the current line.

## Line-number gutter

Set `WidgetEditorOptions.ShowLineNumbers = true` to reserve a fixed left gutter.
It renders one-based logical line numbers as right-aligned ASCII digits followed
by one spacer column. The natural width tracks the document's line-count digit
width and remains fixed while text scrolls horizontally. A wrapped line is
numbered only on its first visual row; each continuation row leaves the label
blank. When the natural gutter would consume the final text column, the editor
suppresses it and restores it after a wider arrange.

`WidgetStyleRole.EditorGutter` styles ordinary gutter rows.
`WidgetStyleRole.EditorGutterCurrentLine` styles every visible wrapped row of
the caret's logical line independently of `HighlightCurrentLine`. Applications
may therefore emphasize only the gutter, only the text band, both, or neither.

The gutter is decorative. A primary-button sequence that begins in it is
consumed without changing the caret or selection. Wheel input over the gutter
still scrolls, and a selection drag that begins in text may cross the gutter and
autoscroll. This release deliberately does not add a general-purpose decoration,
marker, breakpoint, or gutter click-callback API.

## Themes and compatibility

The built-in dark and light palettes provide a muted neutral current-line
background when a gray indexed or RGB shade is available. Eight-color terminals
use an opposing neutral foreground/background pair; terminals lacking the
required color axis safely fall back through the existing theme rules.
Applications can replace the complete `EditorCurrentLine` style through
`WidgetTheme.Parts` or a scoped editor `Styles` override.

Both options are disabled by default, preserving existing presentation. The
public additions are additive: `HighlightCurrentLine` and `ShowLineNumbers` on
`WidgetEditorOptions`, plus the appended `EditorCurrentLine`, `EditorGutter`,
and `EditorGutterCurrentLine` roles. `AssemblyVersion` remains `1.0.0.0`, target
frameworks remain .NET 8, .NET 9, and .NET 10, and Icod.DCurses 2.5.2 remains
the sole direct runtime dependency.

## Sample and verification

The editor sample enables both options. Move through short and wrapped lines to
verify that the band and current gutter style follow the logical caret line.
Narrow the terminal to observe continuation labels and gutter suppression; click
the gutter to confirm it leaves selection unchanged, then drag from text across
it. Automated tests cover default-off compatibility, digit thresholds, invariant
labels, narrow suppression, wrapping, theme precedence, caret/pointer geometry,
bounded work, and package-only consumption on all supported frameworks.

## Install

```text
dotnet add package Icod.Widgets --version 1.7.0
```
