# Icod.Widgets 1.1.0

Icod.Widgets 1.1.0 adds a reusable, bounded single-document editing foundation
while preserving the 1.0 API and assembly identity.

## Highlights

- Exact UTF-16 documents retain mixed CR, LF, and CRLF endings and provide
  indexed lines, immutable snapshots, revisions, checkpoint identity, atomic
  transactions, and bounded undo/redo.
- `WidgetTextEditor` adds Unicode text-element navigation, directional selection,
  selection replacement, word movement/deletion, indentation/outdentation,
  configurable newlines/indentation, insert/overwrite and read-only modes, and
  one-transaction bracketed paste.
- Bounded projection supports tabs, wide text, combining/ZWJ clusters, no-wrap
  and wrapped presentation, horizontal and vertical scroll ranges, pointer drag,
  captured selection, wheel scrolling, and monotonic autoscroll.
- Clipboard work is explicit and application-owned. Typed requests/results guard
  revision, selection, focus, attachment, and view/document identity; failed Cut
  never deletes, stale completion never mutates, and text is never silently truncated.
- Focused caret intent lets the application coordinate DCurses cursor position and
  insert/overwrite style leases without giving Widgets ownership of the session.
- `WidgetTextInput` gains selection, read-only, clipboard, undo/redo, contextual
  edit commands, and caret intent while retaining its 1.0 normalization and limits.

## Integration

The package targets net8.0, net9.0, and net10.0, retains assembly version
`1.0.0.0`, and has one direct runtime dependency: `Icod.DCurses 2.4.0`.

Start with the [editing guide](https://github.com/uniblab/Icod.Widgets/blob/v1.1.0/docs/Editing-Guide.md)
and the [editable in-memory sample](https://github.com/uniblab/Icod.Widgets/tree/v1.1.0/samples/Icod.Widgets.Editor.Sample).
Applications continue to own event loops, async dispatch, clipboard policy, file
encoding and I/O, atomic save/backup/conflict behavior, and terminal leases.

Tabs, multi-document workspace policy, Save As workflows, search/replace dialogs,
and printing are not part of this release. They remain application or later-widget
work for dedit.

## Compatibility and qualification

The [1.1 API baseline](https://github.com/uniblab/Icod.Widgets/blob/v1.1.0/docs/Public-API-Baseline-1.1.md)
is additive over the retained [1.0 baseline](https://github.com/uniblab/Icod.Widgets/blob/v1.0.0/docs/Public-API-Baseline-1.0.md).
See [W1113 qualification](https://github.com/uniblab/Icod.Widgets/blob/v1.1.0/docs/W1113-Stable-Qualification.md)
for exact automated scope, package inspection, live-terminal limitations, and the
owner merge/tag checklist.
