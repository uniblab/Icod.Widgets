# Icod.Widgets 1.4.0 candidate

This source prepares mutable insertion policies for applications such as dedit.
It has not been merged, tagged, or published.

## Changes

- `WidgetTextEditor.NewLine` selects LF, CRLF, or CR for future Enter edits.
- `WidgetTextEditor.Indentation` selects a spaces-and-tabs prefix for future
  Tab and Shift+Tab edits.
- Constructor options remain the initial settings. Changing either policy does
  not rewrite document text, discard view state, or reset undo/redo history.
- Invalid values are rejected while retaining the prior setting.

## Compatibility

The two public properties are additive. The package targets net8.0, net9.0,
and net10.0, keeps assembly version `1.0.0.0`, and has one direct runtime
dependency: `Icod.DCurses 2.5.0`. Applications continue to own line-ending
conversion, encoding, file saves, and search.

## Verification before release

PR validation must build, test, pack, and run the package consumer on Linux,
Windows, and macOS. Review the exact package version and notes before an
owner-approved merge and tag. A new NuGet package must be published before
dedit changes its dependency from Widgets 1.3.1.
