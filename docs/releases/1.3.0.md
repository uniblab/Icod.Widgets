# Icod.Widgets 1.3.0

Icod.Widgets 1.3.0 brings foreground/background color themes to the reusable
terminal controls while retaining the 1.0 assembly identity and 1.2 document
workspace contracts.

## Highlights

- `WidgetTheme.Parts` holds immutable full styles for parts and states.
  `widget.Styles` scopes overrides to its descendants; `host.SetTheme` changes
  the active theme without resetting focus or modal state.
- Controls, multiline editing and selection, tabs, status, scrollbars,
  drop-downs, menus, dialogs, pickers, and game UI paint their owned cells.
  The active tab remains distinct while the editor has focus.
- `WidgetPalette.Create(session.PresentationCapabilities)` selects dark or
  light styles from DCurses' advertised RGB, indexed, axis, and attribute
  support. A terminal may render the requested physical colors differently.
- The gallery includes seven pages and cycles dark, light, and default styles
  with Ctrl+T. It retains its headless `--smoke` path.

## Try it

Install in a .NET project with `dotnet add package Icod.Widgets --version 1.3.0`.
To run the gallery from a fresh checkout:

```text
git clone https://github.com/uniblab/Icod.Widgets.git
cd Icod.Widgets
dotnet run --project samples/Icod.Widgets.Gallery.Sample -c Release -f net10.0
```

See the [root README](https://github.com/uniblab/Icod.Widgets/blob/main/README.md)
for the application-loop example and the
[gallery guide](https://github.com/uniblab/Icod.Widgets/blob/main/samples/Icod.Widgets.Gallery.Sample/README.md)
for keys and widget families.

## Compatibility and scope

Targets net8.0, net9.0, net10.0; assembly version `1.0.0.0`; sole direct
dependency `Icod.DCurses 2.5.0`. The old six-role constructor/deconstructor
remains. Older binary consumers were exercised with the new DLL. App-owned
document lifetime, search execution, file writes, and presentation loops are
unchanged. See the [public API baseline](https://github.com/uniblab/Icod.Widgets/blob/main/docs/Public-API-Baseline-1.3.md)
and [stable qualification](https://github.com/uniblab/Icod.Widgets/blob/main/docs/W1310-Stable-Qualification.md)
for exact gates and limitations.
