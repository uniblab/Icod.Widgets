# Icod.Widgets 1.5.0

Icod.Widgets 1.5.0 adds linewise clipboard operations to the multiline editor.
Applications continue to own clipboard transport and document file I/O.

## Highlights

- Copy or Cut with no selection exports the current logical line, including
  its exact CR, LF, or CRLF terminator when one exists. Cut removes the line
  only after the application reports successful clipboard export, as one
  undoable edit.
- Clipboard requests and results expose optional `IsLinewise` metadata.
  A linewise Paste with no selection inserts at the current line start.
  Pasting over a selected range replaces that range normally. When an
  unterminated copied line is inserted ahead of existing text, the editor
  adds its current `NewLine` as a separator.
- The editor sample retains linewise metadata for its local copy and
  process-local fallback. A different external clipboard value is plain text.

## Try it

Install the package in a .NET project:

```text
dotnet add package Icod.Widgets --version 1.5.0
```

From a repository checkout, run the in-memory editor sample:

```text
dotnet run --project samples/Icod.Widgets.Editor.Sample -c Release -f net10.0
```

Open a file containing at least two lines, press Ctrl+Home, Ctrl+C, Down,
then Ctrl+V. The copied line appears before the second line. Ctrl+Z undoes
the paste. The sample does not write the file. See the
[editor sample guide](../../samples/Icod.Widgets.Editor.Sample/README.md)
for Cut, clipboard status, and insertion policy controls.

## Compatibility

The `IsLinewise` properties are additive; existing clipboard request/result
constructors and deconstruction shape remain available. The package targets
net8.0, net9.0, and net10.0, retains assembly version `1.0.0.0`, and has
`Icod.DCurses 2.5.0` as its sole direct runtime package dependency.
The library is LGPL-3.0-or-later; samples and tests are GPL-3.0-or-later.
