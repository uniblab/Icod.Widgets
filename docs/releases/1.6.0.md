# Icod.Widgets 1.6.0

Icod.Widgets 1.6.0 improves menu interaction for editor-style applications.

## Highlights

- A one-row menu bar remains visible while content-sized dropdowns overlay the
  document. Labels and shortcuts align inside a padded, bordered surface.
- Alt plus a heading mnemonic opens its first enabled command. Up/Down wrap,
  Left/Right switch headings, and Escape closes the root dropdown and restores
  the previous focus. Nested submenus unwind one level at a time.
- User-defined themes control menu colors, mnemonic styles and optional pointer
  hover highlighting. Hover does not change keyboard selection or invoke commands.
- Selection covers the whole command row, including shortcuts and check marks.

## Compatibility

The package targets net8.0, net9.0 and net10.0, retains assembly version
`1.0.0.0`, and keeps `Icod.DCurses 2.5.0` as its sole direct runtime dependency.
Existing menu definitions and constructors remain available. Menu bars should
be arranged in one row; standalone popup menus retain caller-supplied bounds.
