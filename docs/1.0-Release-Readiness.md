# Icod.Widgets 1.0 Release Readiness

**Source package version:** `1.0.0`
**Stable gate:** W1014 live terminal qualification remains open.

W1001–W1013 implementation and resumed interactive corrections are recorded in
[W1013 evidence](W1013-Interactive-Acceptance.md). The gallery, editor and
roguelike have real terminal modes; deterministic smoke paths use the same
application controllers. Regression coverage includes input, rendering,
modal/popup lifecycle and asynchronous picker boundaries.

The stable source prepares exact `1.0.0` package metadata, a package-only
consumer, curated [release notes](releases/1.0.0.md), and a tag workflow using
the existing library template pattern from `uniblab/.github`. The workflow
requires notes, Release build/tests, sample smoke, exact version package and
matching symbols, and package-only consumption before NuGet.org and GitHub
Packages publication. GitHub Release follows both publishing jobs and includes
checksums. The NuGet Trusted Publishing policy uses `release.yaml` and the
`Release` environment.

PR validation builds and tests `net8.0`, `net9.0`, and `net10.0` on Windows,
macOS and Linux, runs all sample smokes, checks package selection and symbols,
and restores a consumer from the produced package. Consult
[Icod.Widgets PR #1](https://github.com/uniblab/Icod.Widgets/pull/1) for the
current exact-head CI result.

## Stable gate remains open

Follow [W1014](W1014-Stable-Qualification.md) to record exact-head live terminal
results in applicable Windows/macOS/Linux and x64/ARM64 environments. A test PTY,
smoke runner or green CI cannot establish visual, pointer and operator
acceptance on a real terminal.

After the owner merges, verify the resulting `main` commit passes its six-platform
Release validation. The owner may then tag that validated commit `v1.0.0` once
the W1014 record is complete. Pushing the tag triggers package publication and
GitHub Release creation. No merge, tag or publication has been performed.
