# Icod.Widgets 1.0 Release Readiness

**Candidate:** `1.0.0-rc.1`

## Complete automated gates

- Library/test/sample solution builds with warnings as errors for net8/net9/net10.
- Deterministic behavior tests cover host lifecycle, layout, forms, lists,
  drop-downs, menus, dialogs, providers, pickers, and game UI controls.
- Gallery, editor, and roguelike public-API smoke workflows pass.
- Package-only consumer restores and runs from the local release-candidate nupkg.
- Package declares LGPL-3.0-or-later, one direct dependency
  (`Icod.DCurses 2.3.1`), and contains only README, license, and framework DLL/XML
  assets. Tests/samples are GPL-3.0-or-later and excluded.
- Public API baseline/fingerprint and per-tranche evidence are recorded.

## Stable-release gate still open

W1014 requires exact-head live evidence on Windows, macOS, and Linux terminals,
plus applicable x64/ARM64 smoke witnesses. Exercise every control, resize and
compact layouts, Unicode input, keyboard-only and supported pointer input,
failed filesystem navigation, modal focus restoration, and clean Q/Escape exits.

After that evidence passes, update package/project version to `1.0.0`, confirm
the assembly version remains `1.0.0.0`, rerun package verification, and prepare
the `v1.0.0` tag/release notes. NuGet publication and GitHub Release remain
separate actions requiring explicit authorization.
