# Icod.Widgets 1.0 Release Readiness

**Candidate:** `1.0.0-rc.2`

W1001–W1013 implementation includes the resumed interactive corrections in
[W1013 evidence](W1013-Interactive-Acceptance.md). The gallery, editor and
roguelike now have real terminal modes, and deterministic smoke paths use the
same application controllers. New regressions cover previously missing live
input, rendering, scope/lifecycle and asynchronous boundaries.

Automated gates: Staging build for net8/net9/net10; deterministic behavior suite;
three public sample smoke workflows; package-only consumption; LGPL payload,
sole direct dependency (`Icod.DCurses 2.3.1`), and API fingerprint. GitHub Actions
runs the standard test platform and sample smoke workflows on Windows/macOS/Linux.
Consult PR #1 for the current SHA and run conclusions.

## Stable gate remains open

Follow [W1014](W1014-Stable-Qualification.md) to record exact-head live terminal
results, including relevant x64/ARM64 environments. A test PTY, smoke runner or
CI success does not establish visual/pointer/operator acceptance on a real terminal.

When applicable evidence passes, update to exact `1.0.0`, retain assembly
`1.0.0.0`, rerun all automated/package gates and reconcile curated release notes,
README and CHANGELOG. Tagging, NuGet publication and GitHub Release remain
separate release actions. No package has been published.
